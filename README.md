# ୨୧ Chapter Journal ୨୧

A lightweight, AI-assisted organizer for long conversations. You choose where a chapter ends; the connected language model creates an editable title, summary, timeline, character changes, clues, and unresolved threads.

## Features

- Manual chapter boundaries
- Editable AI-generated chapter records
- Floating chapter index and navigation
- Source-change detection
- Markdown export
- English interface with multilingual story output

## Install

Copy the `chapter-journal` folder to:

`SillyTavern/public/scripts/extensions/third-party/`

Then restart or refresh SillyTavern.

## Use

Select the open-book icon on a message, or open the floating journal button and choose `End at Latest Message`. Review the generated record, then select `Save Chapter`.
